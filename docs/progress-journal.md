# Progress Journal — a régua da sua evolução

Não meça o progresso por cursos assistidos ou tecnologias listadas. Meça pelas dores que
você fabricou e bateu dentro do Hermes. Escreva uma entrada por sessão de estudo. Este
arquivo, mais o git history, é o seu portfólio de verdade.

## Template de entrada

```
### [DATA] — Dor #NN — <tópico>

- **Need:** por que estudei isso / qual problema ou meta serviu.
- **Where:** domain / parte do Hermes.
- **Dor que fabriquei:** a falha que provoquei de propósito.
- **O que observei/medi:** latência, erro, lock, queue — o que vi acontecer.
- **Solução que implementei:** o que fiz para resolver.
- **O que quebrou ou melhorou:** o resultado antes/depois.
- **Trade-offs que entendi:** o que a solução me custou.
- **Onde a spec errou:** qualquer lacuna entre a spec e a realidade (a nota de mais alto
  valor).
- **Próxima dor que isso puxou:** a semente da próxima sessão.
- **Commit(s):** hashes/links para o git history.
```
